# Discordo JJ para Windows

Compartilhamento de tela estilo Discord: tela inteira ou janela, som de um aplicativo só
(ou do PC inteiro sem a voz da chamada), microfone, chat e status "Assistir" no seu perfil
do Discord.

## Baixar

👉 **[Baixar a versão mais recente](https://github.com/LucaSant02/telinha-releases/releases/latest)**
— baixe o arquivo `DiscordoJJ-Setup-x.y.z.exe` e execute.

O app já abre no servidor oficial: `https://telinha.lucaseverton12.workers.dev`.

> O instalador não tem assinatura digital. Se o Windows mostrar "O Windows protegeu o
> computador", clique em **Mais informações › Executar assim mesmo**.

## Atualizações

O app procura atualizações sozinho ao abrir. Quando houver uma versão nova, ele baixa em
segundo plano e pergunta se você quer reiniciar para atualizar.

## Status no Discord

Com o Discord aberto no PC, ao compartilhar a tela pelo app seu perfil mostra
"Compartilhando a tela" com o botão **Assistir**. Seus amigos clicam no seu nome no canal
de voz → **Assistir** e entram direto na sala. Dá para desligar no seletor de tela.

Prefere usar sem instalar? Abra https://telinha.lucaseverton12.workers.dev no Chrome ou Edge.
